## Overview

Baby Audio Grainferno is a granular processor that slices incoming audio into microscopic grains and reassembles them in time-stretched, pitch-shifted, or randomized patterns for textural sound design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Baby Audio Grainferno** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Grain Engine** | Adjustable grain size, density, and position for smooth to glitchy textures |
| **Pitch Scatter** | Randomized grain pitch variation for shimmering and chorus effects |
| **Time Stretch** | Grain-based time stretching without pitch artifacts |
| **Freeze** | Capture a grain cloud snapshot for infinite drone and pad generation |
